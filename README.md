# 🚀 Areakart

Areakart is a web application that helps users discover which instant delivery services are available in their area.

Instead of downloading multiple apps and checking availability one by one, users can simply search by PIN code or use their current location to instantly view all supported delivery services.

---

## 🌟 Features

- 📍 Detect Current Location
- 🔍 Search by PIN Code
- 🛒 View Available Delivery Apps
- ❤️ Save Favorite Services
- 🕒 Search History
- 🔐 User Authentication
- 📱 Responsive Design
